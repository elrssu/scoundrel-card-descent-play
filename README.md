# Scoundrel Card Descent — Playtest

[Play the latest public HTML5 build](https://elrssu.github.io/scoundrel-card-descent-play/)

A solo, browser-based card dungeon crawl. This public repository contains **playtest build assets only**; the development source remains private.

## Gameplay

Each chamber presents four cards. Choose three and leave one to carry into the next chamber, or skip a full chamber when the rules allow. Clubs and Spades are foes, Diamonds are weapons, and Hearts are remedies. Fight with an equipped weapon or barehanded, manage your vitality and the weapon's shrinking limit on foes, and clear the deck to score. Victories can continue into another dungeon. An in-game tutorial walks through the basics.

Standard mode uses a 44-card dungeon; Easy mode uses the full 52-card deck.

## Current playtest features

- Weathered card artwork and a hooded skull card back.
- Responsive mobile and desktop layouts, including improved card title sizing.
- Remaining durability on an equipped weapon adds to the score when a dungeon is cleared.
- Unused weapons and remedies in the final chamber add supply bonuses to the victory score.
- Barehanded Fighting challenge: a 31-card dungeon with no Diamonds, where every foe must be fought without a weapon.
